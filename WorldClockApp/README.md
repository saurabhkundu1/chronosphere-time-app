# ChronoSphere (Android App)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](../../LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Android%207.0%2B-green.svg)](https://developer.android.com)
[![Compile SDK](https://img.shields.io/badge/Compile%20SDK-37-brightgreen.svg)](https://developer.android.com)

An offline Android world clock application for saved cities, overlap meeting times, and a home-screen widget.

For comprehensive documentation, architecture overview, and guides, refer to the root [README.md](../../README.md).

## Quick Build

```powershell
# Windows
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest
.\gradlew.bat lintDebug

# Linux / macOS
./gradlew assembleDebug
./gradlew testDebugUnitTest
./gradlew lintDebug
```

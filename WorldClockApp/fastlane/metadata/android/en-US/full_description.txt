ChronoSphere is a beautiful, real-time world clock application that displays the current time in 5 major cities around the globe: New York, London, Tokyo, Sydney, and Dubai.

Key Features:
• Real-time clock updates every second
• Displays 5 global cities with their respective time zones
• Beautiful card-based Material Design UI
• Home screen widget (2x4) for quick access
• Modern blue globe logo with clock hands and timezone markers
• No ads, no tracking - completely privacy-focused
• No internet permissions required - works entirely offline
• Open source under GPL v3 license

The app provides an intuitive interface showing each city's name and current time with live updates. The home screen widget allows you to check world times without opening the app.

Perfect for travelers, remote workers, or anyone with friends and family across different time zones.
